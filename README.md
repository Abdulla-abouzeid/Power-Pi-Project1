# Bank Customer Churn Dashboard

Interactive Power BI dashboard analyzing churn across 10,000 bank customers.

## Key Insights
- Overall churn rate: 20.4%
- Germany has the highest churn (32.4%), about double France and Spain
- Female customers churn more (25.1%) than male (16.5%)
- Customers aged 45–64 churn at roughly 50%

## Tools
Power BI, DAX, Power Query
